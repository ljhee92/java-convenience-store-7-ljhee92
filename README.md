# java-convenience-store-precourse

## 💻 프로그램 진행 순서
1. 파일에서 상품, 행사 목록을 읽어 들인다.
2. 환영 인사와 상품 목록을 출력한다.
3. 구매할 상품명과 수량을 입력 받는다.
   * 올바른 형식으로 입력했는지 확인한다.
   * 존재하는 상품을 입력했는지 확인한다.
4. 프로모션 중인 상품을 입력했다면
    * 프로모션 재고 + 일반 재고 수량보다 적거나 같게 주문했는지 확인한다.
    * 프로모션 적용 수량만큼 가져왔는지(N+1로 나누었을 때 나머지가 없는지) 확인한다. -> 가져오지 않았다면 추가 수령 가능 수량을 안내한다.
    * 추가 수령 허용 여부에 따라 주문 내역에 반영한다.
    * 가져온 수량이 프로모션 재고보다 많다면 할인 미적용 수량을 안내한다.
    * 할인 미적용 구매 여부에 따라 주문 내역에 반영한다.
5. 프로모션 중이 아닌 상품을 입력했다면
   * 일반 재고 수량보다 적거나 같게 주문했는지 확인한다.
6. 멤버십 할인 여부를 묻는다.
7. 구매 내역, 증정 내역, 총구매액, 행사할인, 멤버십할인, 내실돈을 계산하고 출력한다.
8. 재구매 여부를 묻는다.

## 📋 기능 목록
### 사용자 입력
1. 파일 입출력
- [ ] 상품 목록
- [ ] 행사 목록

2. 구매할 상품과 수량
- [ ] ``[상품명-수량],[상품명-수량]``의 형식

3. 프로모션 적용 상품 추가 여부 선택
- [ ] 프로모션 적용 상품을 해당 수량보다 적게 가져왔을 때, ``Y/N`` 선택 가능

4. 프로모션 미적용 상품 정가 결제 여부 선택
- [ ] 프로모션 재고 부족으로 미적용 상품을 정가로 결제할지 ``Y/N`` 선택 가능

5. 멤버십 할인 적용 여부 선택
- [ ] 멤버십 할인 적용 여부 ``Y/N`` 선택 가능

6. 추가 구매 여부 선택
- [ ] 영수증 출력 이후 업데이트된 재고에서 추가 구매 여부 ``Y/N`` 선택 가능

7. 잘못된 값 입력 시 재입력
- [ ] ``IllegalArgumentException`` 발생 후 그 부분부터 재입력 받기

### 출력
1. 예외 상황 시 오류 메시지 출력
- [ ] "[ERROR]"로 시작하는 지정된 오류 메시지 출력
- [ ] 구매할 상품과 수량 형식이 올바르지 않은 경우: ``[ERROR] 올바르지 않은 형식으로 입력했습니다. 다시 입력해 주세요.``
- [ ] 존재하지 않는 상품을 입력한 경우: ``[ERROR] 존재하지 않는 상품입니다. 다시 입력해 주세요.``
- [ ] 구매 수량이 재고 수량을 초과한 경우: ``[ERROR] 재고 수량을 초과하여 구매할 수 없습니다. 다시 입력해 주세요.``
- [ ] 기타 잘못된 입력의 경우: ``[ERROR] 잘못된 입력입니다. 다시 입력해 주세요.``

2. 환영인사, 상품명, 가격, 프로모션 이름, 재고 안내
- [ ] 재고가 0개라면 ``재고 없음`` 출력

3. 영수증
- [ ] 구매 내역 : 구매한 상품명, 수량, 가격
- [ ] 증정 내역 : 프로모션 적용된 상품명, 수량
- [ ] 산출한 금액 정보 : 총 구매액, 행사할인, 멤버십할인, 내실돈

### 할인
1. 프로모션
- [ ] 오늘 날짜가 프로모션 기간에 포함된 경우에만 할인 적용
- [ ] N개 구매 시 1개 무료 증정
- [ ] 하나의 상품에 하나의 프로모션만 적용
- [ ] 프로모션 재고 내에서만 적용 가능
- [ ] 프로모션 적용 가능 상품을 고객이 해당 수량보다 적게 가져오면, 필요한 수량을 안내
- [ ] 프로모션 재고 부족 시 프로모션 혜택을 받지 못하는 수량을 정가로 결제하게 됨을 안내

2. 멤버십
- [ ] 프로모션 미적용 금액의 30% 할인 적용
- [ ] 최대 한도 8,000원

### 재고 관리
- [ ] 재고 수량에 따라 결제 가능 여부 확인
- [ ] 고객이 구매한 상품의 수량만큼 재고에서 차감
- [ ] 프로모션 재고가 별도로 존재
- [ ] 프로모션 기간 중이라면 프로모션 재고 우선 차감, 이후 일반 재고 차감

### 최종 결제 금액 계산
- [ ] 총 구매액 = 상품별 가격 * 수량
- [ ] 최종 결제 금액 = 총 구매액에 프로모션 및 멤버십 할인 정책 반영
