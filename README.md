# java-convenience-store-precourse

## 편의점
* 구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템

## 기능 목록
1. 재고 관리
- [ ] 상품의 재고 수량에 따라 결제 가능 여부 확인
- [ ] 결제된 수량만큼 해당 상품의 재고에서 차감
- [ ] 재고를 차감하여 최신 재고 상태를 유지, 다음 고객에게 정확한 재고 정보 제공

2. 프로모션 할인
- [ ] 오늘 날짜가 프로모션 기간 내에 포함된 경우에만 할인 적용
- [ ] N개 구매 시 1개 무료 증정(Buy N Get 1 Free)
- [ ] 프로모션 혜택은 프로모션 재고 내에서만 적용 가능
- [ ] 프로모션 기간 중이라면 프로모션 재고를 우선 차감, 프로모션 재고가 부족하면 일반 재고 차감
- [ ] 프로모션 적용 가능한 상품을 고객이 해당 수량보다 적게 가져왔다면, 필요 수량을 추가로 가져오면 혜택을 받을 수 있다고 안내
- [ ] 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 한다면, 일부 수량에 대해 정가로 결제하게 됨을 안내

3. 멤버십 할인
- [ ] 프로모션 미적용 금액의 ``30%`` 할인
- [ ] 프로모션 적용 후 남은 금액에 대해 멤버십 할인 적용
- [ ] 최대 한도 ``8,000원``

4. 파일 입출력
- [ ] 상품 목록, 행사 목록 파일 입출력 통해 불러오기

5. 사용자 입력
- [ ] 구매할 상품과 수량을 입력 받기. 상품명, 수량은 ``하이픈(-)``으로, 개별 상품은 ``대괄호([])``로 묶어 ``쉼표(,)``로 구분
- [ ] 프로모션 적용 상품에 대해 해당 수량보다 적게 가져온 경우, 그 수량만큼 추가 여부를 ``Y/N``으로 입력받기
- [ ] 프로모션 재고가 부족하여 일부 수량을 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제할지 여부를 ``Y/N``으로 입력받기
- [ ] 멤버십 할인 적용 여부를 ``Y/N``으로 입력받기
- [ ] 추가 구매 여부를 ``Y/N``으로 입력받기

6. 출력
- [ ] 환영인사, 상품명, 가격, 프로모션 이름, 재고 출력. 재고가 0이라면 ``재고없음``을 출력
- [ ] 프로모션 적용 상품에 대해 해당 수량보다 적게 가져온 경우, 그 수량만큼 추가할 것인지 안내 출력
- [ ] 프로모션 재고가 부족하여 일부 수량을 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제할 것인지 안내 출력
- [ ] 멤버십 할인 적용 여부를 묻는 안내 출력
- [ ] 영수증(구매 상품 내역, 증정 상품 내역, 금액 정보) 출력
- [ ] 추가 구매 여부를 묻는 안내 출력
- [ ] 사용자가 잘못된 값을 입력했을 때 "[ERROR]"로 시작하는 오류 메세지와 함께 상황에 맞는 안내 출력

7. 예외 처리
- [ ] 사용자가 잘못된 값을 입력했을 때 ``IllegalArgumentException``을 발생
- [ ] 에러 메시지 출력 후 그 부분부터 재입력 받기

## 테스트 목록
1. 재고 관리
- [ ] 상품의 재고가 충분하다면 결제 가능한지 확인한다.
- [ ] 상품의 재고가 충분하지 않다면 결제 불가한지 확인한다.
- [ ] 결제된 수량만큼 해당 상품의 재고에서 차감하는지 확인한다.

2. 프로모션 할인
- [ ] 오늘 날짜가 프로모션 기간 내에 포함되었는지 확인한다.
- [ ] 프로모션 재고보다 구매 요청 수량을 적게 입력했다면 증정 수량을 반환하는지 확인한다.
- [ ] 프로모션 재고보다 구매 요청 수량을 많이 입력했다면 정가 결제 수량을 반환하는지 확인한다.
- [ ] 구매 요청 수량 + 증정 수량만큼 프로모션 재고에서 차감하는지 확인한다.

3. 멤버십 할인
- [ ] 멤버십 할인을 적용하지 않으면 할인 금액이 0인지 확인한다.
- [ ] 멤버십 할인을 적용하면 금액의 ``30%``를 할인하는지 확인한다.
- [ ] 멤버십 할인의 최대 적용 금액이 ``8,000원``인지 확인한다.

4. 파일 입출력
- [ ] 상품 목록을 파일 입출력을 통해 잘 불러오는지 확인한다.
- [ ] 행사 목록을 파일 입출력을 통해 잘 불러오는지 확인한다.
